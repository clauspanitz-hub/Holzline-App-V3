# Sets, Standorte und Bestandsführung

Phase-1-Bestand nur an Material/Produkt reicht nicht: Sets existieren nur in Shopify ohne eigenen Lagerbestand; physischer Bestand liegt an Standorten (Hamburg, Dahlenburg, In Bearbeitung). Produkt-Stücklisten verbrauchen Material; Set-/Varianten-Stücklisten dürfen Material und Produkt mischen. Baubare Varianten werden aus der Summe über alle Standorte berechnet; ob Material-Zeilen mitzählen, ist je Set konfigurierbar. Varianten-Struktur kommt per Shopify-Import, Stücklisten-Mapping über Options-Regeln plus Overrides.

**Status:** accepted

**Considered Options:** Bestand pro Shopify-Variante; Set als lagergeführtes Produkt; Material-Varianten für unterschiedliche Ausbeuten
