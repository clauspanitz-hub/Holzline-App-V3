# Zusammenstellen aus Bestellung (Set-Variante)

Bestellpositionen können eine **Set-Variante** verknüpfen (manuell in Prüfung und Schnellerfassung; kein Shop-Auto-Match in diesem Schnitt). Offene Bestellung → Todo **Zusammenstellen** (Werkstatt). **Los** öffnet Dialog mit Standort und BOM-Vorschau; Speichern bucht die komplette Varianten-Stückliste (Produkte und Materialien) an einem Standort ab, ohne Set-Bestand; Negativ mit Warnung; volle Todo-Menge; leere BOM blockiert Speichern. Keine Bewegungs-Historie (wie Fertigen).

**Considered Options:** Auto-Match Set/Variante aus Shopify; Teilmengen; Historie-Einträge; nur Produktzeilen der BOM abbuchen
