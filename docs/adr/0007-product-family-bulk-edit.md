# Produktfamilie, Serien-Mindestbestand und Mehrfachbearbeitung

Serienanlage übernimmt Mindestbestand aus Dialog (sonst Vorlage bei Produkten). Produkte erhalten das Feld **Produktfamilie** (Serienanlage = Basisname); UI mit Filter und Gruppenköpfen; einmaliger Backfill-Vorschlag aus Name ohne Farb-Suffix. Mehrfachbearbeitung setzt nur Mindestbestand, Tags sowie bei Produkten Familie und Ist-Vorlage.

**Status:** accepted

**Considered Options:** Gruppierung nur über Namensähnlichkeit; Massenänderung von Name/Stückliste/Bestand
