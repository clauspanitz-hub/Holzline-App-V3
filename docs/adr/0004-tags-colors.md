# Tags und Farben mit Medium

Materialien und Produkte bekommen Tags (Gruppierung/Filter, Katalog + freie Neueinträge) und optional je eine Farbe aus einem Katalog. Farben haben ein Medium (Lack, PLA); Vorschläge für Stückliste und Set-Zuordnung nur bei gleichem Medium. Vorschläge werden angezeigt, nicht stillschweigend eingefügt.
