# Set-Zuordnung über Katalogfarbe (Batch)

Pro Shopify-Options-Name werden Medium, Artikel-Typ und Vorlage/Familie gesetzt. Alle Options-Werte erscheinen als Liste: Katalogfarbe per Namens-Match (bei Unklarheit Kandidaten-Dropdown), Artikel = Serie/Familie + Farbe, Menge immer 1. Typische Ketten: Ringfarbe→Ring (Lack), Kerzenfarbe→Kerzenset, Zahlenfarbe→Ziffernset (PLA).

**Status:** accepted

**Considered Options:** Einzeln-Formular Wert→Artikel; stilles Auto-Anlegen; Menge ≠ 1 in der Options-Zuordnung
