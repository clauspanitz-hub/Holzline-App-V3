# Set-Zuordnung über Katalogfarbe

Shopify-Optionswerte werden im Set-Assistenten zuerst über **Medium (je Options-Name)** und **Katalogfarbe** gematcht; danach Lagerartikel mit dieser Farbe vorgeschlagen. Fehlende Produkte können im Assistenten per Serienanlage/Vorlage bewusst nachgelegt werden. Gespeichert bleibt die Zuordnung Option → Lagerartikel.

**Status:** accepted

**Considered Options:** Nur Artikel-Dropdown ohne Katalog; stilles Auto-Anlegen fehlender Produkte; Medium bei jedem Optionswert neu wählen
