# Set-Zuordnung über Katalogfarbe (Batch)

Pro Shopify-Options-Name werden Medium, Artikel-Typ und Vorlage/Familie gesetzt. Alle Options-Werte erscheinen als Liste: Katalogfarbe per Namens-Match inkl. Aliase und Dunkel/Hell-Umordnung (bei Unklarheit Kandidaten-Dropdown), Artikel bevorzugt über Vorlagen-Serie (Name ohne Farbe), sonst Familie/Basisname; Menge immer 1. Typische Ketten: Ringfarbe→Ring (Lack), Kerzenfarbe→Kerzenset, Zahlenfarbe→Ziffernset (PLA).

**Status:** accepted

**Considered Options:** Einzeln-Formular Wert→Artikel; stilles Auto-Anlegen; Menge ≠ 1 in der Options-Zuordnung; nur exakter Farbstring ohne Aliase
