# Negativbestand und Unterdeckung beim Fertigen

Beim Fertigen und bei manuellen Bestandskorrekturen sind Negativbestände erlaubt. Die UI warnt sichtbar; eine Bestell-/Einkaufs-Todo-Liste folgt erst in Phase 3. Alternative (atomarer Abbruch bei Unterdeckung) wurde verworfen, damit die Werkstatt Produktion nicht blockiert.
